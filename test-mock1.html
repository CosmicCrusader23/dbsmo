1 / 18單選題

某校知道三件事：(1) 所有參加編程隊的同學都有參加數學隊；(2) 沒有中一學生參加數學隊；(3) 有些參加辯論隊的同學也參加了編程隊。以下哪一項必定為真？

  1. A沒有中一學生參加辯論隊。
  2. B有些參加數學隊的同學沒有參加編程隊。
  3. C有些參加辯論隊的同學不是中一學生。
  4. D所有參加辯論隊的同學都有參加數學隊。
顯示答案

必定為真

答案

C

由 (3)，有一位同學 X 同時在辯論隊和編程隊；由 (1)，X 也在數學隊；由 (2)，X 不是中一學生。所以「有些參加辯論隊的同學不是中一學生」必定為真，X 就是例子。其他三項都有反例：假設全校只有兩位同學，甲在辯論隊、編程隊和數學隊，不是中一學生；乙是中一學生，只參加辯論隊。三件事都成立，但 A（乙是中一學生，在辯論隊）、B（數學隊只有甲，他也在編程隊）、D（乙不在數學隊）都不成立。

重點

連續推理：由「有些」找出一個具體的人，再一步步用「所有」和「沒有」推下去；要說明一句不一定為真，就構造一個所有條件都成立、但這句不成立的例子。

2 / 18單選題

以下哪一個條件，對所有整數 x 和 y 都和 !(x > 3 && (y <= 5 || x == y)) 的值相同？

  1. Ax <= 3 && (y > 5 || x != y)
  2. Bx <= 3 || y > 5 && x != y
  3. C(x <= 3 || y > 5) && x != y
  4. Dx <= 3 || y > 5 || x != y
顯示答案

把條件取反

答案

B

用兩次德摩根定律：!(P && Q) = !P || !Q，而 Q 是 y <= 5 || x == y，所以 !Q = y > 5 && x != y。合起來是 x <= 3 || (y > 5 && x != y)；因為 && 比 || 先計算，括號可以省去，就是選項 B。

重點

!(P && Q) = !P || !Q，!(P || Q) = !P && !Q，每一層都要換；> 的相反是 <=，== 的相反是 !=；&& 比 || 先計算。

3 / 18單選題

把 1、2、3、4、5、6 依次放入一個隊列（先放入的先取出）。然後重複以下步驟，直至隊列變空：由隊頭取出一個數 v；如果 v 是奇數，輸出 v；否則把 v ÷ 2 放入隊尾。輸出的次序是甚麼？

  1. A1 3 5 1 3 1
  2. B1 1 3 5 3 1
  3. C3 5 1 3 1 1
  4. D1 1 3 1 5 3
顯示答案

隊列：奇數輸出，偶數減半放回

答案

A

逐步寫下隊列（左邊是隊頭）：1 2 3 4 5 6 → 取 1，輸出 → 取 2，放入 1：3 4 5 6 1 → 取 3，輸出 → 取 4，放入 2：5 6 1 2 → 取 5，輸出 → 取 6，放入 3：1 2 3 → 取 1，輸出 → 取 2，放入 1：3 1 → 取 3，輸出 → 取 1，輸出。輸出 1 3 5 1 3 1。

重點

隊列先進先出：新放入的數排在最後，要等前面的數全部取出後才輪到它。追蹤時每一步都寫下整個隊列。

4 / 18單選題

把 1、2、3、4、5 依次放入一個堆疊，中途可以隨時取出（取出的總是最後放入而還未取出的數）。全部取出後，記下取出的次序。以下哪些次序可能出現？

  1. I.3 2 5 4 1
  2. II.3 1 2 4 5
  3. III.2 1 5 4 3
  4. IV.1 4 2 3 5
  5. V.1 3 2 5 4
  1. A只有 I、III、IV 和 V
  2. B只有 I 和 III
  3. C只有 I、III 和 V
  4. D只有 I、II、III 和 V
顯示答案

堆疊：哪些取出次序可能出現？

答案

C

判斷方法：某個數 x 取出時，比 x 小而還未取出的數都在堆疊裏，之後必須由大到小取出。I（3 2 5 4 1）：放 1、2、3，取 3、2；放 4、5，取 5、4；再取 1，可以。II（3 1 2 4 5）：取出 3 後 1、2 在堆疊裏，下一個卻是 1，不可以。III（2 1 5 4 3）：放 1、2，取 2、1；放 3、4、5，取 5、4、3，可以。IV（1 4 2 3 5）：取出 4 後 2、3 在堆疊裏，下一個卻是 2，不可以。V（1 3 2 5 4）：可以。所以只有 I、III 和 V。

重點

堆疊的取出次序：某數取出之後，比它小而未取出的數必須由大到小取出。

5 / 18單選題

四位數（1000 至 9999）之中，有多少個的各位數字由左至右不遞增（每一位都不大於前一位，可以相等）？例如 9530、9533、7777 都是，9354 不是。

  1. A210
  2. B715
  3. C495
  4. D714
顯示答案

數字由左至右不遞增的四位數

答案

D

每一個合乎要求的數，都由「選哪 4 個數字（可以重複）」決定：把選出的數字由大到小排好，就是唯一的寫法。按有幾個不同的數字分類：4 個不同，C(10, 4) = 210；3 個不同（其中一個用兩次），C(10, 3) × 3 = 360；2 個不同（用法有 3 + 1、2 + 2、1 + 3 三種），C(10, 2) × 3 = 135；全部相同，10。合共 210 + 360 + 135 + 10 = 715。（也可以用隔板法：4 個數字和 9 塊隔板排成一行，C(13, 4) = 715。）其中只有 0000 不是四位數（最大的數字是 0 時，四位都是 0），所以答案是 714。

重點

「各位數字不遞增或不遞減」：只要數「選哪幾個數字（可以重複）」；可以按有幾個不同的數字分類，再留意 0 和首位的限制。

6 / 18單選題

A、B、C、D、E 五人隨機排成一行，每一種排法的機會相同。A 排在 B 前面，而且 C 和 D 都排在 B 後面（都不一定相鄰）的概率是多少？

  1. A1/8
  2. B1/12
  3. C1/24
  4. D1/4
顯示答案

A 在 B 前，C、D 在 B 後

答案

B

只看 A、B、C、D 四人的先後次序：E 站在哪裏都不影響這四人之間的次序，而 4! = 24 種先後次序機會相同。合乎要求的次序：B 前面只有 A，後面是 C 和 D，即 A B C D 或 A B D C，共 2 種，所以概率是 2/24 = 1/12。（核對：120 種排法之中剛好有 10 種合乎要求。）

重點

只關心某幾個人的先後次序時，可以忽略其他人：k 個人的 k! 種先後次序機會相同，數出合乎要求的次序就可以。

7 / 18單選題

一枚棋子由 (0, 0) 出發，每一步可以由 (x, y) 走到 (x + 1, y + 2) 或 (x + 2, y + 1)。以下哪一點是棋子可以到達的？

  1. A(100, 100)
  2. B(2, 70)
  3. C(99, 100)
  4. D(50, 52)
顯示答案

每步走 (1, 2) 或 (2, 1)

答案

D

每一步 x + y 都增加 3，所以走了 k 步後 x + y = 3k；而且每一步 x、y 各最少加 1、最多加 2，所以 k ≤ x ≤ 2k、k ≤ y ≤ 2k。(50, 52)：x + y = 102，k = 34，而 34 ≤ 50 ≤ 68、34 ≤ 52 ≤ 68：走 (1, 2) 18 次、(2, 1) 16 次，得 (18 + 32, 36 + 16) = (50, 52)，可以到達。(2, 70)：k = 24，但 x = 2 < 24，不可能。(100, 100) 和 (99, 100)：x + y 不是 3 的倍數。

重點

找不變量：這裏每一步 x + y 都增加 3，所以 x + y 除以 3 的餘數不變（一直是 0），這樣就能排除很多點；再用「每步最多、最少」定出範圍。

8 / 18單選題

以下插入排序把 a 由小到大排好。程式輸出甚麼？

int a[7] = {5, 2, 8, 1, 9, 3, 7}, cmp = 0;
for (int i = 1; i < 7; i++) {
    int x = a[i], j = i - 1;
    while (j >= 0) {
        cmp++;
        if (a[j] > x) { a[j + 1] = a[j]; j--; }
        else break;
    }
    a[j + 1] = x;
}
cout << cmp;
  1. A9
  2. B13
  3. C15
  4. D21
顯示答案

插入排序比較了多少次？

答案

B

每個數向左比較：比它大的就向右移（比較一次、移動一次），遇到不比它大的就停（再比較一次）；移到最前面就不用再比較。i = 1（2）：比 5，移動，到了最前面，1 次。i = 2（8）：比 5，停，1 次。i = 3（1）：比 8、5、2，全部移動，到了最前面，3 次。i = 4（9）：比 8，停，1 次。i = 5（3）：比 9、8、5，移動，比 2，停，4 次。i = 6（7）：比 9、8，移動，比 5，停，3 次。合共 1 + 1 + 3 + 1 + 4 + 3 = 13。

重點

插入排序的比較次數 = 移動次數（逆序對的數目）+ 沒有移到最前面的次數。

9 / 18單選題

A、B、C、D、E 五人賽跑，名次各不相同（第一名最快）。已知：D 緊接在 A 之後到達；D 和 E 的名次相差 2（中間剛好隔一人）；E 比 C 快；C 不是第一名，也不是最後一名。誰是第三名？

  1. AA
  2. BE
  3. CD
  4. DC
顯示答案

五人賽跑的名次

答案

C

A、D 是相連的兩個名次，逐一試 D 的名次：D 第二（A 第一）→ E 第四，C 不可以是第一、第五，只能第三，但 E 要比 C 快，矛盾。D 第三（A 第二）→ E 第一或第五；E 第五就不可能比 C 快，所以 E 第一；C 不可以是第五，只能第四，B 第五：E A D C B。D 第四（A 第三）→ E 第二，餘下第一、第五給 B、C，但 C 兩個都不可以。D 第五（A 第四）→ E 第三，C 要在 E 之後，但第四、第五已有人，矛盾。所以名次是 E、A、D、C、B，第三名是 D。

重點

分情況推理：選一個可能性最少的條件（這裏是「A、D 相連」）逐一試，每一種情況都用其他條件檢查。

10 / 18單選題

把 1 至 10 排成一個圓圈，計算每對相鄰兩數之和（共 10 個和）。要令這 10 個和之中最大的一個盡量小，這個最大的和最小可以是多少？

  1. A12
  2. B11
  3. C13
  4. D15
顯示答案

排成一圈：相鄰兩數之和

答案

A

先找下限：10 有兩個不同的鄰居，最小的可能是 1 和 2，所以總有一個和不小於 10 + 2 = 12。再構造：2、10、1、9、3、8、4、7、5、6（最後的 6 和 2 相鄰），10 個和是 12、11、10、12、11、12、11、12、11、8，最大是 12。兩樣都有，所以答案是 12。

重點

求「最大值最小可以是多少」：先找一個不能更好的理由（下限），再排出一個剛好達到下限的例子；兩樣都有才算答完。

11 / 18填充題

以下程式輸出甚麼？

int x = 3, s = 0;
for (int i = 1; i <= 2026; i++) {
    x = (x * x + 1) % 10;
    s += x;
}
cout << s;

只填一個整數。

A：
顯示答案

有起始段的週期：求總和

答案

A：7085

x 依次是 3 → 0 → 1 → 2 → 5 → 6 → 7 → 0 → …（例如 7 × 7 + 1 = 50，50 % 10 = 0）。每一步先改 x 再加，所以 s 加上的是 0、1、2、5、6、7、0、1、…，週期長 6，每個週期的和是 21；開始時的 3 沒有加進 s。2026 = 6 × 337 + 4：337 個完整週期共 337 × 21 = 7077，餘下 4 步加上 0 + 1 + 2 + 5 = 8。輸出 7077 + 8 = 7085。

重點

找週期時要分開起始段和週期；求總和時，用「完整週期數 × 一個週期的和 + 餘下的部分」，並留意先改後加還是先加後改。

12 / 18填充題

1 至 1000 之中，有多少個數恰好能被 2、3、5 之中的兩個整除？（例如 6 可以：它能被 2 和 3 整除，但不能被 5 整除；30 不可以，因為它能被三個都整除。）

只填一個整數。

B：
顯示答案

恰好被其中兩個數整除

答案

B：233

能被 2 和 3 整除即能被 6 整除，有 166 個；能被 2 和 5 整除即能被 10 整除，有 100 個；能被 3 和 5 整除即能被 15 整除，有 66 個；三個都能整除即能被 30 整除，有 33 個。166 + 100 + 66 = 332 之中，能被 30 整除的數在三組都數了，而它們一個也不應該計算，所以要減三次：332 − 3 × 33 = 233。

重點

「恰好兩個」：兩兩的個數相加，再減去 3 倍「三個都是」的個數。

13 / 18填充題

以下程式輸出甚麼？

int c = 0;
for (int i = 1; i <= 1000; i *= 2)
    for (int j = 0; j < i; j += 3)
        c++;
cout << c;

只填一個整數。

C：
顯示答案

外層乘 2、內層加 3

答案

C：346

i 依次是 1、2、4、…、512，共 10 個（1024 大於 1000 就停）。j = 0、3、6、… 而且小於 i，次數是 i ÷ 3 向上取整：1、1、2、3、6、11、22、43、86、171，合共 346。

重點

j 由 0 開始每次加 3、小於 i：次數是 i ÷ 3 向上取整。

14 / 18填充題

桌上有 2026 粒石子。兩人輪流取石子，每次只可以取 1、3 或 4 粒，取走最後一粒的人勝出。先取的人第一步應該取多少粒，才能保證勝出？寫出所有這樣的取法。

由小到大填所有取法，用空格分隔，例如 2 4。

D：
顯示答案

取石子：每次取 1、3 或 4 粒

答案

D：1 3

由小到大找必敗位置（輪到你時，無論怎樣取都會輸）：0 粒必敗；1、3、4 粒可以一次取完，必勝；2 粒只能取 1 粒，留下 1 粒給對手，必敗；5、6 粒可以取到剩 2 粒，必勝；7 粒無論取 1、3、4 粒都留下必勝位置，必敗……列下去會發現必敗位置是除以 7 餘 0 或 2 的數，每 7 個一循環。2026 除以 7 餘 3，是必勝位置。要留給對手一個必敗位置：取 1 粒剩 2025（餘 2），取 3 粒剩 2023（餘 0），都可以；取 4 粒剩 2022（餘 6），不可以。答案是 1 和 3。

重點

取石子遊戲：由小到大列出必勝和必敗位置，找出循環；必勝的走法是把對手留在必敗位置。

15 / 18填充題

1 至 100 之中，有多少個數寫成二進制時剛好有三個 1？（例如 11 的二進制是 1011，有三個 1。）

只填一個整數。

E：
顯示答案

二進制裏剛好有三個 1

答案

E：33

100 以下的數最多有 7 位二進制（26 = 64 ≤ 100 < 128 = 27）。由 7 個位選 3 個放 1，有 C(7, 3) = 35 個數，全部小於 128。其中大於 100 的：如果最高的兩位（64 和 32）都是 1，再加一個較低的位，得 112、104、100、98、97，大於 100 的只有 112 和 104；如果最高兩位不是都是 1，最大只有 64 + 16 + 8 = 88。所以答案是 35 − 2 = 33。

重點

「二進制有 k 個 1」的數目用組合計算：n 個位選 k 個；有上限時，把超出上限的另外數出來減去。

16 / 18填充題

以下程式讀入 1 至 100 之中的整數 t。有多少個 t 會令程式輸出 7？

int t, lo = 1, hi = 100, cnt = 0;
cin >> t;
while (lo <= hi) {
    int mid = (lo + hi) / 2;
    cnt++;
    if (mid == t) break;
    else if (mid < t) lo = mid + 1;
    else hi = mid - 1;
}
cout << cnt;

只填一個整數。

F：
顯示答案

二分搜尋：哪些 t 令迴圈執行 7 次？

答案

F：37

每次比較都把範圍分成兩半。第 1 次比較只會找到一個數（50），第 2 次最多兩個（25 和 75），第 k 次最多 2k−1 個。前 6 次最多 1 + 2 + 4 + 8 + 16 + 32 = 63 個，而按中點切分時，各次比較的範圍大小依次是 100；49 至 50；24 至 25；11 至 12；5 至 6；2 至 3；1，到第 6 次每段仍有 2 至 3 個數，所以前 6 層都是滿的，剩下 100 − 63 = 37 個都要第 7 次比較才找到。（用程式代入每個 t 核對過：比較 1 至 7 次的 t 分別有 1、2、4、8、16、32、37 個。）

重點

二分搜尋第 k 次比較最多找到 2k−1 個數；把比較的過程看成一棵樹，數每一層有多少個數。

17 / 18填充題

如果一個正整數由左至右讀和由右至左讀都一樣，就叫做迴文數，例如 7、44、2112、10301。（a）比 2026 大的最小迴文數是 G1，比 2026 小的最大迴文數是 G2。求 G1 和 G2。（b）1 至 9999 之中有 H1 個迴文數。另外，把所有正整數迴文數（不限於 9999 以內）由小到大排列，第 2026 個是 H2。求 H1 和 H2。

每格只填一個整數。G1、G2 都正確才得 G 的 1.5 分；H1、H2 都正確才得 H 的 1.5 分。

G1：G2：H1：H2：
顯示答案

迴文數

答案

G1：2112；G2：2002；H1：198；H2：1027201

（a）四位迴文數的形式是 abba（a 不是 0）。a = 2 時由小到大是 2002、2112、2222、…，所以 G1 = 2112，G2 = 2002（再小的是 1991）。（b）迴文數由前一半的數字決定：一位數 9 個（1 至 9）、兩位數 9 個（11 至 99）、三位數 90 個（aba：a 有 9 種、b 有 10 種）、四位數 90 個（abba），所以 H1 = 9 + 9 + 90 + 90 = 198。五位數（abcba）、六位數（abccba）各有 900 個，累計 198 + 900 + 900 = 1998 個，所以第 2026 個是七位迴文數中的第 2026 − 1998 = 28 個。七位迴文數由前四位（1000 至 9999）決定，前四位越小，整個數越小；第 28 個的前四位是 1000 + 27 = 1027，所以 H2 = 1027201。

重點
