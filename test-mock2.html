1 / 13單選題

以下程式輸出甚麼？

int a = -7, b = 2;
double x = a / b;
double y = (double) a / b;
int z = a / b * b + a % b;
cout << x + y + z;
  1. A-13.5
  2. B-14.5
  3. C-14
  4. D-13
顯示答案

負數的整數除法和類型轉換

答案

A

C++ 的整數除法向 0 取整：−7 / 2 = −3（不是 −4），而 −7 % 2 = −1（餘數和被除數同號）。x：a / b = −3，存入 double 後是 −3.0。y：(double) a 先把 a 變成 −7.0，再除以 2，得 −3.5。z：由左至右，a / b * b = −3 × 2 = −6，加上 a % b = −1，得 −7（a / b * b + a % b 一定等於 a）。x + y + z = −3 − 3.5 − 7 = −13.5，輸出 -13.5。

重點

整數除法向 0 取整，負數也一樣（−7 / 2 = −3），餘數和被除數同號（−7 % 2 = −1）；存入 double 也救不回小數部分；(double) a / b 先轉換 a，再除。

int c = 0;
for (int x = -2; x <= 2; x++)

顯示答案

else 跟哪一個 if？

答案

C

else 跟最近的、還未配對的 if 配對，所以迴圈內等於 if (x > 0) { if (y > 0) c += 1; else c += 10; }，x ≤ 0 時甚麼都不做。x = 1、2 時：y = 1、2 各加 1，y = −2、−1、0 各加 10，每個 x 加 2 + 30 = 32。兩個 x 共 64，輸出 64。

重點

else 總是和最近的、還未有 else 的 if 配對，與縮排無關；不確定時自己加上大括號再讀。

3 / 13單選題

以下程式輸出甚麼？

void g(int &x, int y) {
    x += y;
    y += x;
}
int main() {
    int a = 1, b = 2;
    for (int i = 0; i < 3; i++) {
        g(a, b);
        g(b, a);
    }
    cout << a << " " << b;
}
  1. A1 2
  2. B379 268
  3. C127 65
  4. D21 34
顯示答案

一個引用參數，一個普通參數

答案

D

g 只會改第一個參數：g(a, b) 等於 a += b，g(b, a) 等於 b += a；y += x 只改副本。(a, b) 依次是 (1, 2) → (3, 2) → (3, 5) → (8, 5) → (8, 13) → (21, 13) → (21, 34)，輸出 21 34。

重點

參數名稱前有 & 才是引用：在函數裏改它，就是改調用時傳入的變量；沒有 & 的參數只是副本。調轉參數次序調用時，被改的就是另一個變量。

4 / 13單選題

以下程式輸出甚麼？

int a = 6, b = 13;
cout << (a & b == 4) << " " << (a << 1 + 1) << " " << (a ^ b | a & 3);
  1. A1 24 11
  2. B0 24 11
  3. C0 13 11
  4. D1 13 3
顯示答案

位元運算的優先次序

答案

B

C++ 的優先次序：+ 先於 <<，<< 先於 ==，== 先於 &，& 先於 ^，^ 先於 |。第一個：b == 4 是 0，6 & 0 = 0。第二個：1 + 1 = 2，6 << 2 = 24。第三個：先算 a & 3 = 110 & 011 = 010 = 2，再算 a ^ b = 0110 ^ 1101 = 1011 = 11，最後 11 | 2 = 1011 | 0010 = 1011 = 11。輸出 0 24 11。

重點

&、^、| 比 == 低：a & b == c 是 a & (b == c)。位移 <<、>> 比 == 高，但比 +、− 低：2 << 1 == 4 是 (2 << 1) == 4，值為 1；1 << 2 + 1 是 1 << 3。& 先於 ^ 先於 |。不肯定就加括號。

5 / 13單選題

以下程式輸出甚麼？

int a = 0, b = 0, c = 0;
for (int i = 1; i <= 10; i++)
    if (i % 2 == 0 && ++a > 2 || i % 3 == 0 && ++b > 1)
        c++;
cout << a << " " << b << " " << c;
  1. A5 3 4
  2. B10 10 6
  3. C5 2 4
  4. D5 3 2
顯示答案

&& 和 || 裏的 ++

答案

C

&& 先於 ||，所以條件是「(i 是偶數 && ++a > 2) || (i 是 3 的倍數 && ++b > 1)」。&& 左邊不成立時不計算右邊；|| 左邊成立時也不計算右邊。偶數的 i（2、4、6、8、10）都會令 a 加 1，a 最後是 5；由 i = 6 起 ++a > 2 成立，c 在 i = 6、8、10 各加 1，而且這三次右邊都不計算。左邊不成立時才計算右邊：i = 2、4 不是 3 的倍數；i = 3 時 b 變成 1，不大於 1；i = 9 時 b 變成 2，條件成立，c 再加 1。i = 6 雖然是 3 的倍數，但左邊已經成立，++b 不會執行。所以 a = 5，b = 2，c = 4。

重點

&& 先於 ||；&& 左邊不成立、|| 左邊成立時，右邊都不會計算，右邊的 ++ 也不會執行。

7 / 13填充題

以下程式想輸出陣列 a 之中最長的「連續上升段」的長度（例如 2 3 5 是長度 3 的上升段）。程式實際輸出甚麼？

int a[8] = {4, 6, 7, 2, 3, 5, 8, 9};
int best = 0, cur = 0;
for (int i = 1; i < 8; i++) {
    if (a[i] > a[i - 1]) cur++;
    else {
        best = max(best, cur);
        cur = 0;
    }
}
cout << best;

只填一個整數。

M：
顯示答案

最長的上升段（程式有錯）

答案

M：2

i = 1、2：6 > 4、7 > 6，cur 變成 1、2。i = 3：2 < 7，best = max(0, 2) = 2，cur = 0。i = 4 至 7：3、5、8、9 都比前一個大，cur 變成 1、2、3、4，但之後再沒有不上升的情況，迴圈結束時 cur = 4 沒有和 best 比較。輸出 2。要改正：cur 的初值改為 1，上升段斷開時 cur 也重設為 1（一個數本身是長度 1 的段），並在迴圈結束後再做一次 best = max(best, cur)。

重點

讀「想做某件事」的程式時，要照程式實際做的追蹤；找錯時特別留意初值（0 還是 1）和最後一段有沒有處理。

bool twoEqual(int a, int b, int c) {

O：
顯示答案

剛好兩個相等

答案

O：(a == b) + (b == c) + (a == c) == 1

「剛好兩個相等」等於「三個比較 a == b、b == c、a == c 之中剛好一個成立」：如果有兩個成立，例如 a == b 和 b == c，第三個 a == c 也一定成立。C++ 的 true、false 可以當作 1、0 相加，所以可以寫 (a == b) + (b == c) + (a == c) == 1。另一種寫法是「最少一對相等，但不是三個都相等」：(a == b || b == c || a == c) && !(a == b && b == c)。網頁會代入 a、b、c 的不同數值，和參考答案比較。

10 / 13填充題

以下程式輸出甚麼？

int x = 0;
for (int i = 1; i <= 2026; i++)
    x ^= i;
cout << x;

只填一個整數。

P：
顯示答案

1 至 2026 全部 XOR 起來

答案

P：2027

先試小的 n（f(n) 是 1 至 n 全部 XOR 起來）：f(1) = 1，f(2) = 1 ^ 2 = 3，f(3) = 3 ^ 3 = 0，f(4) = 4，f(5) = 1，f(6) = 7，f(7) = 0，f(8) = 8。規律：n 除以 4 餘 0 時 f(n) = n，餘 1 時是 1，餘 2 時是 n + 1，餘 3 時是 0。原因：k 是偶數時，k 和 k + 1 只差最低一位，k ^ (k + 1) = 1；所以由 4 的倍數開始，每 4 個連續的數 XOR 起來是 1 ^ 1 = 0。2026 = 4 × 506 + 2，所以 f(2023) = 0，再 ^ 2024 ^ 2025 ^ 2026：2024 ^ 2025 = 1，1 ^ 2026 = 2027。輸出 2027。

重點

大 n 的 XOR：先試小的 n 找規律；k 是偶數時 k ^ (k + 1) = 1，所以由 4 的倍數開始，每 4 個連續的數 XOR 起來是 0。

把方陣順時針轉 90 度

Integer division of negatives, and casts

Answer

A

C++ integer division rounds toward 0: −7 / 2 = −3 (not −4), and −7 % 2 = −1 (the remainder takes the sign of the number being divided). x: a / b = −3, stored as −3.0. y: (double) a turns a into −7.0 first, and dividing by 2 gives −3.5. z: left to right, a / b * b = −3 × 2 = −6, plus a % b = −1 gives −7 (a / b * b + a % b always equals a). x + y + z = −3 − 3.5 − 7 = −13.5, so the output is -13.5.

Key point

Integer division rounds toward 0, negatives included (−7 / 2 = −3), and the remainder has the sign of the number divided (−7 % 2 = −1); storing in a double cannot bring back the fraction; (double) a / b converts a first, then divides.

Which if does the else belong to?

Answer

C

An else pairs with the nearest unmatched if, so the loop body means if (x > 0) { if (y > 0) c += 1; else c += 10; }, and nothing happens when x ≤ 0. For x = 1 and 2: y = 1, 2 each add 1 and y = −2, −1, 0 each add 10, so each x adds 2 + 30 = 32. The two give 64, so the output is 64.

Key point

An else always pairs with the nearest if that has no else yet, whatever the indentation; when unsure, add the braces yourself and reread.

One reference parameter, one value parameter

Answer

D

C++ precedence: + before <<, << before ==, == before &, & before ^, ^ before |. First: b == 4 is 0, and 6 & 0 = 0. Second: 1 + 1 = 2, and 6 << 2 = 24. Key point
