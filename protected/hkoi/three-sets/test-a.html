1 / 10單選題

一隻蛋從某一層或以上掉下就會破，從較低的層掉下不會破；破了的蛋不能再用，沒有破的可以再用。現在有兩隻相同的蛋和一座 100 層的大廈，要找出蛋會破的最低一層（也可能 100 層都不會破）。最壞情況下，最少要擲多少次才一定能找出答案？

  1. A7
  2. B13
  3. C14
  4. D19
顯示答案

兩隻蛋和 100 層樓

答案

C

反過來問：最多擲 d 次，最多可以處理多少層？第一次應該在第 d 層擲：破了，下面 d − 1 層只剩一隻蛋，要逐層試，剛好還有 d − 1 次；沒有破，還剩 d − 1 次，下一次就在再高 d − 1 層擲，如此類推。所以 d 次最多處理 d + (d − 1) + … + 1 = d(d + 1)/2 層；第一次擲得更高，破了之後就試不完下面的層。13 次最多 91 層，不夠；14 次可以處理 105 層 ≥ 100。所以最少要 14 次。做法：第一隻蛋依次在 14、27、39、50、60、69、77、84、90、95、99、100 層擲，破了就由上一次的下一層起，用第二隻蛋逐層擲。

重點

「最壞情況最少幾次」要同時有做法和不能更少的理由；反過來問「d 次最多能處理多少」往往最清楚。

2 / 10單選題

不斷擲一枚公平的硬幣（H 是正面，T 是反面）。設 A 是第一次出現「連續兩次 H」平均要擲的次數，B 是第一次出現「H 之後緊接 T」平均要擲的次數。以下哪一項正確？

  1. AA = B = 4
  2. BA = B = 6
  3. CA = 6，B = 4
  4. DA = 4，B = 6
顯示答案

HH 和 HT

答案

C

用「現在的狀態」列方程。等 HH：設 a 是由頭開始還要擲的平均次數，a₁ 是最後一個是 H 時還要擲的平均次數。a = 1 + a₁/2 + a/2（擲到 H 進入狀態 H，擲到 T 留在開始）；a₁ = 1 + 0/2 + a/2（再擲到 H 就完成，擲到 T 要由頭開始）。解得 a₁ = 4，a = 6。等 HT：b = 1 + b₁/2 + b/2；b₁ = 1 + 0/2 + b₁/2（擲到 T 就完成，擲到 H 仍然是最後一個是 H）。解得 b₁ = 2，b = 4。兩個結果每兩次出現的機會都是 1/4，但失敗之後的情況不同，所以 A = 6，B = 4。

重點

求「平均要多少次」時，按目前的狀態（例如最後一個是不是 H）列方程；失敗之後回到哪個狀態，決定了快慢。

3 / 10單選題

以下程式讀入整數 a、b（100 ≥ a > b ≥ 1），輸出迴圈的次數。在所有這樣的 (a, b) 之中，哪一對令程式的輸出最大？

int a, b, c = 0;
cin >> a >> b;
while (b != 0) {
    int r = a % b;
    a = b;
    b = r;
    c++;
}
cout << c;
  1. A(100, 99)
  2. B(100, 1)
  3. C(97, 60)
  4. D(89, 55)
顯示答案

輾轉相除最慢的一對

答案

D

每一次 (a, b) 變成 (b, a % b)。要用最多次，每一步的商 a ÷ b（向下取整）都應該是 1，即 a = b + (a % b)。由最後倒推：最後一步之前是 (2, 1)（2 % 1 = 0），再之前是 (3, 2)、(5, 3)、(8, 5)、(13, 8)……每一對都是相鄰的費氏數。不超過 100 的最大費氏數是 89，前一個是 55：(89, 55) → (55, 34) → (34, 21) → (21, 13) → (13, 8) → (8, 5) → (5, 3) → (3, 2) → (2, 1) → (1, 0)，共 9 次。要 10 次的話 a 最少是 144，超過了 100。程式檢查了全部 4950 對，只有 (89, 55) 要 9 次。

重點

找「最慢的輸入」時倒過來想：每一步都走得最少（這裏是商為 1），倒推出最壞的情況；輾轉相除法最慢的是相鄰的費氏數。

4 / 10填充題

以下程式輸出甚麼？

int f(int n) {
    if (n > 100) return n - 10;
    return f(f(n + 11));
}
int main() {
    long long s = 0;
    for (int n = 1; n <= 200; n++) s += f(n);
    cout << s;
}

只填一個整數。

顯示答案

遞歸函數 f

答案

23150

先試 n 接近 100 的情況：f(100) = f(f(111)) = f(101) = 91；f(99) = f(f(110)) = f(100) = 91。一般 90 ≤ n ≤ 100 時 n + 11 > 100，所以 f(n) = f(n + 1)，由 f(101) = 91 一直推下去，f(90) 至 f(100) 都是 91。n < 90 時，由大到小推：n + 11 在 12 至 100 之間，f(n + 11) 已知是 91，所以 f(n) = f(91) = 91。結論：n ≤ 100 時 f(n) = 91，n > 100 時 f(n) = n − 10。總和 = 100 × 91 + (91 + 92 + … + 190) = 9100 + 14050 = 23150。

重點

遞歸展開很長時，先試邊界附近的小例子找規律，再由大到小（或由小到大）證明規律對所有 n 成立。

5 / 10填充題

把 1、2、3、4、5、6 依次放入一個堆疊，途中可以隨時取出（每次取出最上面的數），最後全部取出。一共可以得到多少種不同的取出次序？

只填一個整數。

顯示答案

堆疊可以得到多少種次序？

答案

132

設 c(n) 是 n 個數的答案。看 1 是第幾個取出的：如果 1 是第 k 個取出，那麼在它之前取出的 k − 1 個數，一定是 1 之後放入、又在 1 取出之前取出的數，即 2 至 k，它們之間有 c(k − 1) 種次序；1 取出之後，餘下的 k + 1 至 n 有 c(n − k) 種。所以 c(n) = c(0)c(n − 1) + c(1)c(n − 2) + … + c(n − 1)c(0)，c(0) = 1。c(1) = 1，c(2) = 2，c(3) = 5，c(4) = 14，c(5) = 42，c(6) = 42 + 14 + 2 × 5 + 5 × 2 + 14 + 42 = 132。（這些數叫卡塔蘭數。）

重點

數「有多少種」時，按某個關鍵元素（這裏是 1 第幾個取出）分情況，把問題拆成兩個較小的同類問題，得出遞推式。

6 / 10填充題

以下程式輸出甚麼？

long long s = 0;
for (int x = 1; x <= 1000; x++)
    for (int i = x; i > 0; i -= i & -i)
        s++;
cout << s;

只填一個整數。

顯示答案

i & -i

答案

4938

i & -i 是 i 的二進制最低的那個 1（例如 12 = 1100₂，12 & -12 = 100₂ = 4）。i -= i & -i 就是把最低的 1 去掉，所以內層迴圈的次數等於 x 的二進制有多少個 1，s 就是 1 至 1000 所有數的 1 的個數之和。逐位數：第 k 位（代表 2k）在 0 至 1000 這 1001 個數之中，每 2k+1 個數一循環，前一半是 0，後一半是 1。第 0、1、2 位各有 500 個；第 3 位：1001 = 62 × 16 + 9，有 62 × 8 + 1 = 497 個；第 4 位：1001 = 31 × 32 + 9，有 31 × 16 = 496 個；第 5 至 9 位各有 489 個（例如第 9 位就是 512 至 1000）。合共 500 × 3 + 497 + 496 + 489 × 5 = 4938。

重點

i & -i 是最低的 1，i -= i & -i 每次去掉一個 1；數「1 至 n 共有多少個 1」時逐位計算，每一位每 2k+1 個數一循環。

7 / 10填充題

p 是 1 至 6 的一個排列。以下程式數出 p 之中有多少個數比它前面的所有數都大（第一個數也算）。如果 p 是 1 至 6 的 720 個排列之一，每個的機會相同，程式輸出的平均值是多少？

int mx = 0, c = 0;
for (int i = 0; i < 6; i++)
    if (p[i] > mx) {
        mx = p[i];
        c++;
    }
cout << c;

填一個分數，例如 7/3（化簡與否都可以）。

顯示答案

新高出現了幾次？

答案

49/20

把平均值拆成每個位置的機會再相加。第 i 個數（i = 1 至 6）是新高，等於它是前 i 個數之中最大的；前 i 個數之中每一個做最大的機會相同，所以這個機會是 1/i。平均值 = 1 + 1/2 + 1/3 + 1/4 + 1/5 + 1/6 = (60 + 30 + 20 + 15 + 12 + 10)/60 = 147/60 = 49/20。

重點

平均值可以逐個位置相加；「第 i 個是前 i 個之中最大」的機會是 1/i，因為前 i 個數每一個做最大的機會相同。

8 / 10填充題

3 × 3 的推盤上有 1 至 8 八個方塊和一個空格（_）。每一步可以把空格上下左右的其中一個方塊推進空格。以下 4 個狀態，每個由上至下寫出三行（用 / 分隔）。哪些狀態可以推回 1 2 3 / 4 5 6 / 7 8 _？

  1. I.1 2 3 / 4 5 6 / 8 7 _
  2. II.1 2 3 / 4 _ 6 / 7 5 8
  3. III.8 2 3 / 4 5 6 / 7 1 _
  4. IV.3 1 2 / 4 5 6 / 7 8 _

填可以推回原狀的狀態編號（I = 1、II = 2、III = 3、IV = 4），由小到大，用空格分隔，例如 1 3。

顯示答案

推回原狀

答案

2 4

把方塊由上至下、由左至右排成一列（不計空格），數逆序對（前面的數比後面的大的對數）。左右推方塊不改變這一列的次序；上下推方塊時，被推的方塊在這一列中越過另外兩個方塊，逆序數改變 2、0 或 −2。所以逆序數的奇偶性不變。原狀的逆序數是 0（偶數），所以逆序數是奇數的狀態推不回去。I：1 2 3 4 5 6 8 7，1 個（奇數）；II：1 2 3 4 6 7 5 8，2 個（偶數）；III：8 2 3 4 5 6 7 1，13 個（奇數）；IV：3 1 2 4 5 6 7 8，2 個（偶數）。反過來，逆序數是偶數的狀態都推得回去（程式由原狀出發，找到全部 181440 個可以到達的狀態，正好是逆序數為偶數的那一半）。答案：2 4。

重點

找不變量：看一步操作對「排成一列後的逆序數」有甚麼影響；奇偶不同的狀態一定到達不了。

9 / 10填充題

以下程式數出陣列 a 之中，有多少段連續的數（最少一個數）的和不超過 lim（a 的數都是正整數）。（a）在空格 R、S 填上適當的內容，使程式正確。（b）程式輸出甚麼？（c）sum -= a[l]; 一共執行了多少次？

int main() {
    int a[10] = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3}, lim = 10;
    int l = 0, sum = 0, cnt = 0;
    for (int r = 0; r < 10; r++) {
        sum += a[r];
        while (R) {
            sum -= a[l];
            l++;
        }
        cnt += S;
    }
    cout << cnt;
}

R 填一個條件，S 填一個算式，可以用 sum、lim、r、l、整數和運算符，各最多 12 格（空白不計）；（b）（c）只填一個整數。

R：S：（b）：（c）：
顯示答案

和不超過 10 的連續一段

答案

R：sum > lim；S：r - l + 1；（b）：20；（c）：8

（a）r 每向右移一格，就把 a[r] 加進 sum；如果 sum 超過 lim，就由左邊逐個刪去，直到 sum ≤ lim，所以 R 是 sum > lim。這時以 r 結尾、和不超過 lim 的段，正好是開頭在 l 至 r 的段（開頭再向左，因為全部是正數，和只會更大），共 r − l + 1 段，所以 S 是 r - l + 1。（b）r = 0 至 9 時，以 r 結尾的段數依次是 1、2、3、4、3、1、1、2、1、2，合共 20。其中 r = 4（和 14）刪去 3、1；r = 5（和 19）刪去 4、1、5；r = 6（和 11）刪去 9；r = 8（和 13）刪去 2、6。（c）l 只會向右移，最多由 0 移到 10，所以內層的 sum -= a[l]; 合共最多執行 10 次：整個程式只是一層迴圈的工作量，不是兩層。這個輸入合共刪去 2 + 3 + 1 + 2 = 8 次。

雙指針：右端每次走一步，左端只向右移；所有數都是正數時，以 r 結尾而和不超過上限的段，開頭是連續的 l 至 r，共 r − l + 1 段。

10 / 10填充題

以下程式求陣列 a 最長的嚴格遞增子序列（可以不連續，例如 1 3 7 8）的長度。t[k] 記錄：在已讀的數之中，長 k + 1 的嚴格遞增子序列，最後一個數最小可以是多少。每讀一個數，就用二分搜尋找出 t 之中第一個不小於它的位置，用它取代那個位置的數。（a）在空格 R、S 填上適當的內容，使程式正確。（b）程式輸出甚麼？（c）如果把 R 寫成 t[mid] <= a[i]，程式輸出甚麼？

int main() {
    int a[10] = {3, 1, 9, 3, 9, 2, 7, 7, 8, 8};
    int t[10], len = 0;
    for (int i = 0; i < 10; i++) {
        int lo = 0, hi = len;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (R) lo = mid + 1;
            else hi = mid;
        }
        t[S] = a[i];
        if (lo == len) len++;
    }
    cout << len;
}

R 填一個條件，例如 x != 0；S 只填算式，可以用 lo、hi、整數和運算符，最多 10 格（空白不計）；（b）（c）只填一個整數。

R：S：（b）：（c）：
顯示答案

最長遞增子序列

答案

R：t[mid] < a[i]；S：lo；（b）：4；（c）：6

（a）要找 t 之中第一個不小於 a[i] 的位置：t[mid] < a[i] 時答案在 mid 右邊，lo = mid + 1；否則在 mid 或左邊，hi = mid。所以 R 是 t[mid] < a[i]。迴圈結束時 lo = hi 就是那個位置，S 是 lo（寫 hi 也對）。如果位置是 len，即 t 的數全部都比 a[i] 小，a[i] 就接在最後，len 加 1。（b）t 的變化：3 → [3]；1 → [1]；9 → [1, 9]；3 → [1, 3]；9 → [1, 3, 9]；2 → [1, 2, 9]；7 → [1, 2, 7]；7 → [1, 2, 7]；8 → [1, 2, 7, 8]；8 → [1, 2, 7, 8]。輸出 4（例如 1 3 7 8）。（c）改成 <= 之後，找的是第一個大於 a[i] 的位置，相等的數可以接在後面：前 7 個數之後 t 是 [1, 2, 7]；第二個 7 → [1, 2, 7, 7]；8 → [1, 2, 7, 7, 8]；8 → [1, 2, 7, 7, 8, 8]。輸出 6，即最長的不下降子序列 1 2 7 7 8 8。

重點

最長遞增子序列的快速做法：t[k] 是長 k + 1 的子序列最小的結尾；嚴格遞增時找第一個 ≥ 的位置，不下降時找第一個 > 的位置。

1 / 10Single answer

An egg breaks if dropped from a certain floor or higher, and does not break from lower floors; a broken egg cannot be used again, an unbroken one can. With two identical eggs and a 100-floor building, you must find the lowest floor from which the egg breaks (it may not break even from floor 100). In the worst case, what is the least number of drops that always finds the answer?

  1. A7
  2. B13
  3. C14
  4. D19
Show answer

Two eggs and 100 floors

Answer

C

Ask the reverse question: with at most d drops, how many floors can be handled? The first drop should be at floor d: if it breaks, the d − 1 floors below must be tried one by one with the last egg, using exactly the d − 1 drops left; if not, d − 1 drops remain, and the next drop is d − 1 floors higher, and so on. So d drops handle at most d + (d − 1) + … + 1 = d(d + 1)/2 floors; dropping the first egg any higher leaves too many floors below if it breaks. 13 drops handle at most 91 floors, not enough; 14 handle 105 ≥ 100. So at least 14 drops are needed. A plan: drop the first egg at floors 14, 27, 39, 50, 60, 69, 77, 84, 90, 95, 99, 100 in turn; when it breaks, drop the second egg floor by floor starting just above the previous drop.

Key point

"Fewest in the worst case" needs both a method and a reason nothing better exists; asking the reverse, "how much can d tries handle at most?", is often clearest.

2 / 10Single answer

A fair coin is tossed again and again (H is heads, T is tails). Let A be the average number of tosses until "H then H" first appears, and B the average number until "H then T" first appears. Which is correct?

  1. AA = B = 4
  2. BA = B = 6
  3. CA = 6, B = 4
  4. DA = 4, B = 6
Show answer

HH and HT

Answer

C

Write equations by the current state. Waiting for HH: let a be the average number of further tosses from the start, and a₁ the number when the last toss was H. a = 1 + a₁/2 + a/2 (H moves to state H, T stays at the start); a₁ = 1 + 0/2 + a/2 (another H finishes, T sends you back to the start). Solving gives a₁ = 4 and a = 6. Waiting for HT: b = 1 + b₁/2 + b/2; b₁ = 1 + 0/2 + b₁/2 (T finishes, H still leaves the last toss as H). Solving gives b₁ = 2 and b = 4. Both pairs have chance 1/4 of appearing at any two given tosses, but what happens after a failure differs, so A = 6 and B = 4.

Key point

To find "how many on average", write an equation for each current state (such as whether the last toss was H); where a failure sends you decides how fast it goes.

3 / 10Single answer

This program reads integers a and b (100 ≥ a > b ≥ 1) and prints the number of loop passes. Among all such (a, b), which pair makes the output largest?

int a, b, c = 0;
cin >> a >> b;
while (b != 0) {
    int r = a % b;
    a = b;
    b = r;
    c++;
}
cout << c;
  1. A(100, 99)
  2. B(100, 1)
  3. C(97, 60)
  4. D(89, 55)
Show answer

The slowest pair for Euclid's algorithm

Answer

D

Each pass turns (a, b) into (b, a % b). To use the most passes, every quotient a ÷ b (rounded down) should be 1, that is, a = b + (a % b). Working back from the end: just before the last pass we have (2, 1) (2 % 1 = 0), before that (3, 2), (5, 3), (8, 5), (13, 8), … and every pair consists of consecutive Fibonacci numbers. The largest Fibonacci number not above 100 is 89, and the one before it is 55: (89, 55) → (55, 34) → (34, 21) → (21, 13) → (13, 8) → (8, 5) → (5, 3) → (3, 2) → (2, 1) → (1, 0), 9 passes in all. Ten passes would need a to be at least 144, more than 100. A program checked all 4950 pairs: only (89, 55) takes 9 passes.

Key point

To find the slowest input, think backwards: make every step as small as possible (here, quotient 1) and work back to the worst case; Euclid's algorithm is slowest on consecutive Fibonacci numbers.

4 / 10Fill in

What does this program print?

int f(int n) {
    if (n > 100) return n - 10;
    return f(f(n + 11));
}
int main() {
    long long s = 0;
    for (int n = 1; n <= 200; n++) s += f(n);
    cout << s;
}

Write one integer.

Show answer

The recursive function f

Answer

23150

Try n near 100 first: f(100) = f(f(111)) = f(101) = 91; f(99) = f(f(110)) = f(100) = 91. In general, for 90 ≤ n ≤ 100, n + 11 > 100, so f(n) = f(n + 1), and working down from f(101) = 91, f(90) to f(100) are all 91. For n < 90, work down from larger n: n + 11 lies between 12 and 100, so f(n + 11) is already known to be 91, and f(n) = f(91) = 91. Conclusion: f(n) = 91 for n ≤ 100, and f(n) = n − 10 for n > 100. The total is 100 × 91 + (91 + 92 + … + 190) = 9100 + 14050 = 23150.

Key point

When a recursion is long to expand, try small cases near the boundary to find a pattern, then show it holds for every n by working in order.

How many orders can a stack give?

132

Let c(n) be the answer for n numbers. Look at when 1 is popped: if 1 is the kth number popped, the k − 1 numbers popped before it must have been pushed after 1 and popped before 1, so they are 2 to k, in any of c(k − 1) orders; after 1 is popped, the rest, k + 1 to n, can come out in c(n − k) orders. So c(n) = c(0)c(n − 1) + c(1)c(n − 2) + … + c(n − 1)c(0), with c(0) = 1. c(1) = 1, c(2) = 2, c(3) = 5, c(4) = 14, c(5) = 42, and c(6) = 42 + 14 + 2 × 5 + 5 × 2 + 14 + 42 = 132. (These are the Catalan numbers.)

Key point

To count the possibilities, split by what happens to one key element (here, when 1 is popped), breaking the problem into two smaller ones of the same kind, and get a recurrence.

What does this program print?

long long s = 0;
for (int x = 1; x <= 1000; x++)
    for (int i = x; i > 0; i -= i & -i)
        s++;
cout << s;

Write one integer.

Show answer

i & -i

Answer

4938

i & -i is the lowest 1 in the binary form of i (for example 12 = 1100₂ and 12 & -12 = 100₂ = 4). i -= i & -i removes that lowest 1, so the inner loop runs as many times as x has 1s in binary, and s is the total number of 1s in all the numbers from 1 to 1000. Count bit by bit: among the 1001 numbers 0 to 1000, bit k (worth 2k) repeats every 2k+1 numbers, 0 in the first half and 1 in the second. Bits 0, 1 and 2 are 1 in 500 numbers each; bit 3: 1001 = 62 × 16 + 9, so 62 × 8 + 1 = 497; bit 4: 1001 = 31 × 32 + 9, so 31 × 16 = 496; bits 5 to 9 are 1 in 489 numbers each (bit 9, for example, in 512 to 1000). In total 500 × 3 + 497 + 496 + 489 × 5 = 4938.

Key point

i & -i is the lowest 1, and i -= i & -i removes one 1 each time; to count the 1s in 1 to n, work bit by bit, each bit repeating every 2k+1 numbers.

p is an arrangement of 1 to 6. This program counts how many numbers in p are larger than every number before them (the first number counts). If p is one of the 720 arrangements of 1 to 6, each equally likely, what is the average output?

int mx = 0, c = 0;
for (int i = 0; i < 6; i++)
    if (p[i] > mx) {
        mx = p[i];
        c++;
    }
cout << c;

Write a fraction such as 7/3 (simplified or not).

Show answer

How many new highs?

Answer

49/20

Split the average into the chances for each position and add. The ith number (i = 1 to 6) is a new high exactly when it is the largest of the first i numbers; each of the first i numbers is equally likely to be the largest, so the chance is 1/i. The average is 1 + 1/2 + 1/3 + 1/4 + 1/5 + 1/6 = (60 + 30 + 20 + 15 + 12 + 10)/60 = 147/60 = 49/20.

Key point

Averages can be added position by position; the chance that the ith number is the largest of the first i is 1/i, since each of the first i is equally likely to be the largest.

A 3 × 3 sliding puzzle has eight tiles 1 to 8 and one gap (_). Each move slides a tile next to the gap (above, below, left or right) into the gap. Each of the 4 states below lists its three rows from top to bottom (separated by /). Which states can be slid back to 1 2 3 / 4 5 6 / 7 8 _?

  1. I.1 2 3 / 4 5 6 / 8 7 _
  2. II.1 2 3 / 4 _ 6 / 7 5 8
  3. III.8 2 3 / 4 5 6 / 7 1 _
  4. IV.3 1 2 / 4 5 6 / 7 8 _

Write the numbers of the states that can be slid back (I = 1, II = 2, III = 3, IV = 4), from smallest to largest, separated by spaces, for example 1 3.

Show answer

Back to the start

Answer

2 4

Read the tiles row by row into one line (ignoring the gap) and count the inversions (pairs where an earlier number is larger than a later one). Sliding a tile left or right does not change the order of this line; sliding a tile up or down moves it past two other tiles in the line, changing the inversion count by 2, 0 or −2. So the parity of the inversion count never changes. The start has 0 inversions (even), so states with an odd count cannot be slid back. I: 1 2 3 4 5 6 8 7, 1 inversion (odd); II: 1 2 3 4 6 7 5 8, 2 (even); III: 8 2 3 4 5 6 7 1, 13 (odd); IV: 3 1 2 4 5 6 7 8, 2 (even). Conversely, every state with an even count can be slid back (a program starting from the solved state found all 181440 reachable states, exactly the half with an even count). Answer: 2 4.

Key point

Look for an invariant: see what one move does to the inversion count of the tiles read in a line; states of different parity can never be reached.

This program counts how many runs of consecutive numbers in a (at least one number each) have a sum of at most lim (every number in a is a positive integer). (a) Fill in blanks R and S so that the program is correct. (b) What does the program print? (c) How many times in all is sum -= a[l]; carried out?

int main() {
    int a[10] = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3}, lim = 10;
    int l = 0, sum = 0, cnt = 0;
    for (int r = 0; r < 10; r++) {
        sum += a[r];
        while (R) {
            sum -= a[l];
            l++;
        }
        cnt += S;
    }
    cout << cnt;
}

For R, write a condition, and for S an expression, using sum, lim, r, l, integers and operators, at most 12 boxes each (spaces not counted); for (b) and (c), write one integer.

R:S:(b):(c):
Show answer

Stretches with sum at most 10

Answer

R: sum > lim; S: r - l + 1; (b): 20; (c): 8

(a) Each time r moves right, a[r] is added to sum; if sum exceeds lim, numbers are removed from the left until sum ≤ lim, so R is sum > lim. Then the runs ending at r with sum at most lim are exactly those starting at l to r (starting further left only makes the sum larger, as all numbers are positive), r − l + 1 of them, so S is r - l + 1. (b) For r = 0 to 9, the numbers of runs ending at r are 1, 2, 3, 4, 3, 1, 1, 2, 1, 2, 20 in total. Along the way, at r = 4 (sum 14) 3 and 1 are removed; at r = 5 (sum 19) 4, 1 and 5; at r = 6 (sum 11) 9; at r = 8 (sum 13) 2 and 6. (c) l only moves right, at most from 0 to 10, so the inner sum -= a[l]; runs at most 10 times altogether: the whole program does the work of one loop, not two. For this input it runs 2 + 3 + 1 + 2 = 8 times.

Key point

Two pointers: the right end moves one step at a time and the left end only moves right; with all numbers positive, the runs ending at r within the limit start at l to r, which is r − l + 1 runs.

This program finds the length of the longest strictly increasing subsequence of a (not necessarily consecutive, for example 1 3 7 8). t[k] holds, among the numbers read so far, the smallest possible last number of a strictly increasing subsequence of length k + 1. For each number read, a binary search finds the first position in t whose value is not less than it, and the number replaces that value. (a) Fill in blanks R and S so that the program is correct. (b) What does the program print? (c) If R is written as t[mid] <= a[i], what does it print?

int main() {
    int a[10] = {3, 1, 9, 3, 9, 2, 7, 7, 8, 8};
    int t[10], len = 0;
    for (int i = 0; i < 10; i++) {
        int lo = 0, hi = len;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (R) lo = mid + 1;
            else hi = mid;
        }
        t[S] = a[i];
        if (lo == len) len++;
    }
    cout << len;
}

For R, write a condition such as x != 0; for S, write only an expression using lo, hi, integers and operators, in at most 10 boxes (spaces not counted); for (b) and (c), write one integer.

R:S:(b):(c):
Show answer

The longest increasing subsequence

Answer

R: t[mid] < a[i]; S: lo; (b): 4; (c): 6

(a) We want the first position in t whose value is not less than a[i]: when t[mid] < a[i] the position is to the right of mid, so lo = mid + 1; otherwise it is mid or to its left, so hi = mid. So R is t[mid] < a[i]. When the loop ends, lo = hi is that position, so S is lo (hi also works). If the position is len, every value in t is smaller than a[i], so a[i] is added at the end and len grows by 1. (b) t changes as follows: 3 → [3]; 1 → [1]; 9 → [1, 9]; 3 → [1, 3]; 9 → [1, 3, 9]; 2 → [1, 2, 9]; 7 → [1, 2, 7]; 7 → [1, 2, 7]; 8 → [1, 2, 7, 8]; 8 → [1, 2, 7, 8]. The output is 4 (for example 1 3 7 8). (c) With <=, the search finds the first position greater than a[i], so equal numbers can be added after each other: after the first 7 numbers t is [1, 2, 7]; the second 7 → [1, 2, 7, 7]; 8 → [1, 2, 7, 7, 8]; 8 → [1, 2, 7, 7, 8, 8]. The output is 6, the longest non-decreasing subsequence 1 2 7 7 8 8.

Key point

The fast method for the longest increasing subsequence: t[k] is the smallest ending of a subsequence of length k + 1; for strictly increasing, find the first position ≥ the number, and for non-decreasing, the first position >.
