1 / 30多選題

以下哪些寫法會輸出 2.5？（可選多於一項）

  1. Acout << 5 / 2.0;
  2. Bcout << (double)(5 / 2);
  3. Ccout << (double)5 / 2;
  4. Dcout << 5 / 2 * 1.0;
顯示答案

哪些寫法會輸出 2.5？

答案

A、C：關鍵是做除法那一刻，兩邊是甚麼類型：只要其中一邊是 double，就會做小數除法；兩邊都是 int，結果的小數部分就會被捨去。5 / 2.0 的 2.0 是 double，所以得 2.5。(double)5 / 2 的 (double) 只作用在 5 上，5 先變成 5.0，再除以 2，得 2.5。另外兩個寫法都是先用整數算出 2，cout 輸出 2.0 時只會顯示 2。

考點

int 除以 int 會捨去小數。要得到小數，必須在做除法之前，把其中一邊變成 double。

2 / 30是非題

是非題：在 C++ 中，0.1 + 0.2 == 0.3 的結果是 true。

  1. A對
  2. B錯
顯示答案

0.1 + 0.2 == 0.3？

答案

B：double 用二進制儲存小數。0.1、0.2 和 0.3 在二進制都是無限循環小數，就像十進制的 1/3 = 0.333…，所以只能存最接近的近似值。0.1 + 0.2 的結果約是 0.30000000000000004，而 0.3 存成約 0.29999999999999999，兩者差了一點點，所以 == 得出 false。

0.1 + 0.2  ->  0.30000000000000004
0.3        ->  0.29999999999999999
0.25 + 0.5 == 0.75  ->  true
考點

double 和 float 大多只能儲存近似值，所以不要用 == 比較兩個計算出來的小數。

已知 int a = 50000, b = 50000;。以下哪些寫法能令 c 得到正確的 2500000000（即 a × b）？（可選多於一項）

  1. Along long c = (long long)(a * b);
  2. Blong long c = a * b * 1LL;
  3. Clong long c = (long long)a * b;
  4. Dlong long c = 1LL * a * b;
顯示答案

50000 × 50000 會不會溢出？

答案

C、D：這題和第 1 題（哪些寫法會輸出 2.5）是同一個道理：決定結果的是做乘法那一刻，兩邊是甚麼類型。int 乘 int 的結果也是 int，而 50000 × 50000 = 2500000000，超出了 int 的上限 2147483647，會溢出。(long long)a * b 的轉換只作用在 a 上，a 先變成 long long，乘法就用 long long 計算。1LL * a * b 由左至右，先算 1LL * a，得到 long long，再乘 b。另外兩個寫法都是先用 int 算 a * b，已經溢出。

考點

int 乘 int 的結果仍是 int。要避免溢出，必須在乘法之前把其中一個數變成 long long。

以下兩個程式只差一個 int。它們依次輸出甚麼？

    c++;

  1. A5 和 5
  2. B6 和 6
  3. C5 和 0
  4. D6 和 0
顯示答案

迴圈結束後 i 是多少？

答案

D：程式一：迴圈用的是外面那個 i。i 由 1 數到 5，之後再加 1 變成 6，條件 i <= 5 不成立，迴圈才結束，所以輸出 6。程式二：在 for 裏面寫 int i，等於另外宣告了一個新的變量，名字也叫 i，而且只在迴圈裏存在。迴圈改的是這個新的 i，外面的 i 從來沒有被改過，仍然是 0。迴圈結束後，新的 i 就消失了，cout << i 用的是外面的 i，所以輸出 0。

迴圈正常結束時，迴圈變量停在第一個令條件不成立的值（這裏是 6）。在 for 裏面用 int 宣告的變量是另一個變量，只在迴圈裏有效，而且會遮住外面同名的變量。

    x = x + 1;

}

嵌套迴圈裏的 break

答案

A：break 只會跳出它所在的那一層迴圈，即內層的 j 迴圈；外層的 i 迴圈會繼續。i = 0 時，j = 0 就 break，c 不變；i = 1 時，j = 0 令 c 加 1，j = 1 就 break；i = 2 時，j = 0 和 1 令 c 加 2，j = 2 就 break。共 0 + 1 + 2 = 3。

考點

break 只跳出最內層、包着它的那個迴圈；continue 只跳過這一次餘下的語句，然後進入下一次。

'q' ^ 32 是甚麼？

答案

考點

char 其實是數字（ASCII 碼）。大小寫字母相差 32，而且只差在代表 32 的那一位，所以 c ^ 32 可以切換英文字母的大小寫。

16 / 30單選題教學題

已知 int a[5] = {7, 12, 7, 5, x};。要令這五個數全部 XOR 起來的結果是 6，x 應該是多少？（7 = 0111，12 = 1100，5 = 0101，6 = 0110）

  1. A9（1001）
  2. B6（0110）
  3. C15（1111）
  4. D3（0011）
顯示答案

XOR 的抵消

答案

C：XOR 有三個重要性質：a ^ a = 0（相同的數會互相抵消）、a ^ 0 = a，以及次序可以隨意調換。所以兩個 7 可以放在一起抵消，剩下 12 ^ 5 ^ x = 6。12 ^ 5 = 1100 ^ 0101 = 1001 = 9，所以 9 ^ x = 6。兩邊再同時和 9 做 XOR，得 x = 9 ^ 6 = 1001 ^ 0110 = 1111 = 15。

7 ^ 7     = 0
12 ^ 5    = 1100 ^ 0101 = 1001 = 9
x = 9 ^ 6 = 1001 ^ 0110 = 1111 = 15
教學題：重點是 XOR 的三個性質，以及「a ^ x = b，所以 x = a ^ b」。
考點

a ^ a = 0、a ^ 0 = a，而且 XOR 的次序可以隨意調換。所以如果 a ^ x = b，那麼 x = a ^ b。
